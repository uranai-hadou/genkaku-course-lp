# 玄岩 占い師育成講座・LINE登録広告LP

シャンパンゴールドを基調に、LINEの友だち追加だけを目的として構成した、1カラムの広告LPです。参考LPの大きな見出し、中央に配置した語りかけ、繰り返しの登録案内を取り入れています。

## 読みやすさ

- スマートフォンの本文は22px、通常のLINEボタンは24〜25px。PCの本文は26px。
- 本文はゴシック体、見出しは太めの明朝体。文字色を濃くし、短い文と意味のまとまりごとの改行を使用。
- 小さな英字・肩書き・バッジを削除し、講師紹介や説明文を短く要約。
- 受講の判断に使う文言は20px以上。著作権表記のみスマートフォンで16px。
- プレビュー画像：`preview/mobile-revised.png`、`preview/desktop-revised.png`。

## プレビュー

```sh
npm run dev
```

http://localhost:3000 を開きます。ビルドやライブラリのインストールは不要です。`index.html` を直接ブラウザで開くこともできます。

## 文章を番号で修正する

### 2種類のLP

| 種類 | 通常表示 | 番号付き表示 | 文章一覧 |
|---|---|---|---|
| 既存の本物訴求版 | `/` | `/?review=1&view=page` | `/?review=1&view=list` |
| 稼げる訴求版 | `/income.html` | `/income.html?review=1&view=page` | `/income.html?review=1&view=list` |

既存版の原稿は `index.html`、稼げる訴求版は `income.html` で個別に編集します。稼げる訴求版の番号には `R-` を付けています。「R-A2を変更」「R-C全体を短く」のように指定でき、既存版のA2・Cには影響しません。

稼げる訴求版は「本物」の稼げる霊視占い師へ、をメインに、収入への関心、占いを仕事にする不安、相談者に選ばれる目標を記載しています。講座内容・実績・講師エピソードは提供済みの情報を共通で使用し、未提供の収入額・収益実績・集客支援などは追加していません。森本あきこさんの感想、3か所のLINE導線、無料のオンライン対面霊視と講座案内の条件も引き継いでいます。

稼げる訴求版の原稿一覧は [COPY_GUIDE_INCOME.md](COPY_GUIDE_INCOME.md)。スタイルと動作は共通の `style.css`・`app.js`・`copy-review.js` を使い、LINE URLも `config.js` を共用します。

稼げる訴求版のDとEの間に、独立したグループ `R-M`（M1〜M11）を追加しています。才能・素質が必要なことによる希少性と、四柱推命などに霊視を掛け合わせて鑑定の精度を高めるという玄岩の考えを説明し、ユーザー提供の「第一線で活動する知人が30分8万円で霊視鑑定を行っている」という料金例を掲載しています。料金の一例であり、受講後の収入を示すものではないことを同じ枠内に表示しています。本文の2つの理由は玄岩の見解として記載し、比較データや収益保証としては扱っていません。既存のA〜Lの番号は変更していません。

### 既存版の確認方法

- 番号付きLP：`http://localhost:3000/?review=1&view=page`
- 文章一覧：`http://localhost:3000/?review=1&view=list`
- スマートフォン用サーバーでも同じ `?review=1&view=list` を付けて使えます。
- 「A2を○○に変更」「G5を短く」「I5の条件を変更」「G全体を修正」のように指定できます。
- 一覧の番号コピーボタンは、同じWi-Fi内のHTTP接続にも対応しています。
- 確認モード内のLINEボタンを押すと、その修正番号をコピーします。通常表示では従来どおりLINEへ進みます。
- 固定のグループ・文章番号は `copy-review.js`、番号と現時点の原稿一覧は [COPY_GUIDE.md](COPY_GUIDE.md) にあります。

通常表示には確認用の番号や操作画面は出ません。確認画面の本文は現在のHTMLから取得するため、変更後の文章が自動で反映されます。

### HTMLを直接編集する

1. 稼げる訴求版は `income.html`、既存版は `index.html` をテキストエディタで開きます。
2. 変更したい文章を検索して書き換えます。`income.html` にはグループ番号のコメントも付けています。`<br>` は改行です。
3. `⌘S` で保存し、Chromeで `⌘R` を押して再読み込みすると反映されます。
4. 色・文字サイズ・余白は `style.css`、LINEのリンク先は `config.js` で変更できます。

文章だけの変更なら、タグや `class`、`id` を維持すると番号付き表示もそのまま使えます。確認画面の文章一覧はHTMLから取得しますが、Markdownの原稿一覧は別ファイルなので、直接編集後は必要に応じて更新してください。

### 講座の受け入れ人数

稼げる訴求版に、講師の対応人数に基づく「先着10名限定」を追加しています。R-A5が冒頭、R-B4が定員による受付終了、R-F10がマンツーマン指導による人数制限の理由、R-J6・R-J7が最後の案内です。無料霊視やLINE追加自体の人数制限ではなく、素質があると判断された方の講座申込順で10名を受け入れるという説明です。残席数や募集期限は表示していません。

### 編集時のルール

既存の修正番号は変更しないでください。文章の移動や追加があっても既存番号を振り直さず、新しい番号を追加します。構造を変えた場合は `copy-review.js` の対応先も更新してください。文章の変更時は `COPY_GUIDE.md` の該当原稿も更新します。

同じLINEボタンでも B2・E2・J4 は別の箇所です。番号を指定された場合はその箇所だけを変更し、「LINEボタン全部」と指定された場合は全箇所を変更します。

## 構成

- 提供された講師アイコンと「本物の占い師になりたい」という訴求
- 読者の迷いへの共感
- 霊視と相談者への向き合い方
- 週1回以上の個別指導、受講後も閲覧できる動画教材、定期セミナーの紹介
- 受講生1名の顔写真と感想を後日掲載するための空きスペース
- 提供された実話を要約した講師の物語
- 無料のオンライン対面霊視と、講座案内の条件
- LINE追加から無料霊視の案内へ進む導線（本文内3か所）

ナビゲーション、料金・受講期間・プラン比較、FAQ、別ページへの誘導は設けていません。講師紹介直後のLINE案内ブロックは削除しています。

占い師を目指す方に、Zoomで顔を合わせる無料の霊視を案内します。悩みを聞きながら玄岩が占い師としての素質を確認し、素質があると判断した方のみ講座を案内することを明記しています。所要時間や予約方法など、未提供の条件は追加していません。

公開中の稼げる訴求版には、ユーザー提供の森本あきこさん（papillon blue・セラピスト兼講師）の感想を掲載しています。原文から4か所を抜粋し、全文は開閉して読めます。講師名と文章は、ユーザーが直接編集した最新版に合わせています。写真はユーザー提供の `IMG_4246.jpg` を `assets/morimoto-akiko.jpg` として原寸比率のまま掲載しています。G4・G5を実際の感想に差し替え、G12〜G19に追加文・署名・外部リンク・全文を割り当てました。ローカルの既存版は従来の空きスペースを維持しています。

講師名の下には、提供原稿に基づく「占い師歴10年超え」「累計鑑定数3万件以上」を表示しています。公開中の稼げる訴求版は、ユーザーの編集に合わせてH3〜H7を削除し、最後のエピソードをH8として残しています。ローカルの既存版の6章構成は維持しています。

J5の無料案内とK1のスマートフォン追従ボタンは削除済みです。削除した文章番号は確認画面と文章一覧に欠番として残しています。F0が講座内容の新しい大見出し、F2・F3はF1に統合、F6〜F9が追加した動画・セミナーの文章です。

## LINEの接続

`config.js` の `lineUrl` に公式LINEの友だち追加URLを設定します。未設定時はプレビュー案内を表示し、外部への送信・遷移は行いません。

検索公開する場合は、内容と運営者の公開情報を確認のうえ、`index.html` の `noindex, nofollow` を削除してください。

## ウェブ公開

Sitesで公開します。`.openai/hosting.json` が同じサイトの識別情報です。再公開時はこのサイトを引き継ぎます。

公開対象は稼げる訴求版です。`node publish-static.mjs` により `income.html` と必要な画像・CSS・JavaScriptだけを `dist/` に書き出します。公開URLのトップページも稼げる訴求版になります。元の `index.html` はローカルの別バージョンとして残します。文章の番号付き表示は公開URLに `?review=1&view=page` を付けて確認できます。

HTMLを保存するとローカルには反映されますが、公開サイトへの反映には再公開が必要です。LINEリンクは `config.js` で設定します。

### 森本さんの感想の抜粋を編集する

`income.html` の `voice-excerpts` 内にある4つの段落が、最初に表示する抜粋文です。R-G5（悩み）、R-G12（学びによる変化）、R-G13（サロン開業）、R-G14（現在の活動）のコメントを検索し、その直下の `<p>` 内を書き換えます。`voice-full-text` は別に保存した原文です。

保存後にローカルのChromeを再読み込みすると確認できます。公開サイトに反映するには再公開が必要です。チャットで「R-G12を○○に変更」と指定する場合はこちらで編集・公開できます。

スマホでの改行は `<br class="mobile-copy-break">` で指定できます。PCではこの改行は表示されません。通常の `<br>` は全画面幅で改行されます。感想の抜粋では、HTML内に直接入力した改行もスマホ表示に反映します。
